# Client OS

A small CRM for freelancers to manage leads, projects, and invoices.
- Flow: `Lead → Proposal → Negotiation → Won → Project → Invoice → Paid`

## Tech Stack

- React + Vite
- Tailwind CSS
- React Router
- Axios
- jsPDF
- JSON Server (backend)
## Features

- Home page with quick links to all sections
- Dashboard: revenue, pipeline value, conversion rate, outstanding amount
- Activity timeline of everything that happened
- Kanban pipeline with 5 stages, move deals left/right
- Winning a deal creates a project directly
- Clients: add, search, filter, sort
- Client page shows their opportunities, projects, and invoices
- Projects: milestones checklist, tasks, progress bar
- Invoices: line items, tax, paid/unpaid/overdue status
- PDF download for invoices and project reports
- 3-step form to create new opportunities
- Mobile responsive with collapsible sidebar
